## Tools Generated (9 tools)
- `verify_pan()`: Verify PAN number against NSDL database
- `send_otp()`: Send OTP to customer mobile and email
- `screen_aml()`: Screen customer for AML/PEP compliance
- `verify_bank()`: Verify bank account via penny drop
- `upload_document()`: Upload and store KYC document
- `upload_kra()`: Upload KYC to KRA registry
- `process_ckyc()`: Search and upload CKYC to CERSAI
- `activate_account()`: Generate UCC and DP ID in CBOS
- `send_notification()`: Send notification via SMS/Email/WhatsApp

## How to Use

### Step 1: Drop into your CAMS template repo
```
CAMS repo/
├── src/
│   ├── tools/
│   │   └── *.py              ← DROP ALL TOOL FILES HERE
│   └── config/
│       └── agent_config.json ← REPLACE WITH THIS
```

CAMS auto-discovers all `@tool` functions from `src/tools/` on startup.
No manual registration needed.

### Step 2: Switch executor to ReAct mode (recommended)
In `src/agent/executor.py`, find `_run_graph()` and change:
```python
# FROM (generic 3-step):
graph = self.build_graph(tenant_id)

# TO (LLM drives tool calls — better for multi-step workflows):
graph = self.build_react_graph(tenant_id)
```
