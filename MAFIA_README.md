## Description


## Workflow (10 phases)
- **Initiated**: Assessment request received and tracking ID assigned
- **Profile Fetch**: Employee profile, designation, and department fetched from HRMS
- **Skill Matrix Retrieval**: Role-based skill matrix retrieved and required skills identified
- **Current Skills Evaluation**: Existing skills, certifications, and training history evaluated
- **Self Assessment**: Self-assessment form sent to employee and responses are parsed
- **Manager Assessment**: Manager review triggered and scores collected
- **Gap Analysis**: Skill gap analysis performed and learning recommendations generated
- **Report Generation**: Assessment report compiled and compliance checks validated
- **Completed**: Report delivered to employee, manager, and HR; state locked
- **Needs Correction**: Assessment state when an error or missing data occurs

## Tools (7 tools)
- `fetch_employee_profile()`: Retrieves employee profile, designation, and department — *Darwinbox/Keka HRMS API*
- `fetch_skill_matrix()`: Retrieves role-based skill matrix — *Darwinbox Skill Matrix API*
- `fetch_training_history()`: Retrieves training history of an employee — *LMS API*
- `send_self_assessment()`: Sends a self-assessment form to the employee — *Internal Notification Service*
- `parse_self_assessment()`: Parses responses from the self-assessment form — *Internal Parsing Engine*
- `run_gap_analysis()`: Performs skill gap analysis based on required and current skills — *Internal Skill Gap Engine*
- `generate_report()`: Compiles the assessment report including compliance checks — *Internal Report Service*
